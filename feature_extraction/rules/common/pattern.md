# `pattern`

Cecha single choice, przypisywana wyłącznie przez LLM na podstawie zdjęć, nazwy i opisu produktu.

Wartości: `Solid`, `Striped`, `Plaid`, `Floral`, `Camo`, `Animal Print`, `Polka Dot`, `Other`.

```text
Każdy produkt
└─ pattern → undefined
```
