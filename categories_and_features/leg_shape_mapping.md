# Mapowanie kształtu nogawki (`leg_shape`)

Single choice we wszystkich czterech kategoriach `Pants`. Dopasowanie w biodrach i udach opisuje osobne `fit`.

| Wartość | Znaczenie i wskazówki |
| :--- | :--- |
| `Straight` | Zasadniczo stała szerokość nogawki (`straight`, `straight-leg`). |
| `Tapered` | Nogawka zwężająca się ku dołowi (`tapered`, `carrot fit`). |
| `Wide-Leg` | Wyraźnie szeroka nogawka na całej długości (`wide-leg`, `palazzo`, `hakama`, szerokie `culottes`). |
| `Flared` | Nogawka rozszerzająca się od okolicy kolana (`flared`, `bootcut`, `bell-bottom`, `kick-flare`). |

- Wyraźnie szeroka nogawka o stałej szerokości otrzymuje `Wide-Leg`, nie `Straight`.
- `Flared` oznacza rozszerzenie od kolana, a nie szerokość całej nogawki.
- Sama luźniejsza góra nie oznacza `Wide-Leg`.
- Sam ściągacz lub zamek przy kostce nie przesądza o kształcie nogawki; zakończenie opisuje `cuff_style`.
