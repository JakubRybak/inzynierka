# Mapowanie kaptura (`hood`)

Single choice we wszystkich czterech kategoriach `Sweaters` oraz wszystkich pięciu kategoriach `Jackets & Coats`.

| Wartość | Znaczenie i wskazówki |
| :--- | :--- |
| `With Hood` | Rzeczywisty kaptur: stały, odpinany lub chowany w kołnierzu (`hooded`, `drawstring hood`, `detachable hood`, `stowaway hood`, `concealed hood`). |
| `Without Hood` | Potwierdzony brak kaptura. |

Kategoria nie przesądza o obecności kaptura. Ocenę opieramy na opisie i zdjęciach, również w trenczach, bomberkach i kardiganach.
