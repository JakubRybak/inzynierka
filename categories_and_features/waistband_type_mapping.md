# Mapowanie konstrukcji pasa (`waistband_type`)

Single choice we wszystkich czterech kategoriach `Pants` (`Trousers`, `Cargo Pants`, `Sweatpants & Lounge Pants`, `Jeans`) oraz w `Shorts`. Wspólny słownik: `Structured`, `Elasticized`, `Other`.

| Wartość | Znaczenie i wskazówki |
| :--- | :--- |
| `Structured` | Pas nierozciągliwy, konstrukcyjnie uformowany (`structured waist`, `tailored waistband`). Szlufki i rozporek mogą występować, ale nie są wymagane. Zastępuje dawną wartość `Tailored`. |
| `Elasticized` | Pas elastyczny w całości lub częściowo, np. tylko z tyłu (`elasticized waistband`, `elastic waist`, `elasticized back waistband`, `rib-knit waistband`). |
| `Other` | Inna rozpoznana konstrukcja pasa poza powyższymi klasami. |

- Ocenę opieramy na konstrukcji opisanej w tekście i widocznej na zdjęciach.
- Sam sznurek, szlufki, rozporek lub sposób zakładania nie przesądzają o elastyczności pasa.
- Pas z gumką i szlufkami lub rozporkiem otrzymuje `Elasticized`.
- `Structured` nie oznacza eleganckiego typu całych szortów. Typ `Tailored` w `shorts_type` jest osobną cechą.
