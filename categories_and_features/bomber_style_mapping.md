# Mapowanie typu bomberki (`bomber_style`)

Single choice tylko w `Bombers`.

| Wartość | Znaczenie i wskazówki |
| :--- | :--- |
| `Flight` | Konstrukcja bomberki lotniczej (`MA-1`, `flight jacket`, `aviator bomber`, charakterystyczna kieszeń użytkowa na rękawie). |
| `Varsity` | Konstrukcja kolegialna lub baseballowa (`varsity`, `letterman`, `baseball jacket`, charakterystyczne kontrastowe rękawy i wykończenia). |
| `Other` | Pozostałe rozpoznane typy bomberki, również minimalistyczny blouson. |

`Quilted` i `Blouson` nie są osobnymi wartościami. Pikowana bomberka może nadal być `Flight` lub `Varsity`; samo pikowanie nie wymusza `Other` ani `insulation = Padded`.
